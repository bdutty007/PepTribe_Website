## Workflow

Import one user-supplied page at a time. Preserve original behavior during import. Record its destination and status in PAGES.md. Commit each page separately. For pages containing several custom-code sections, retain their order and any separate header/footer tracking code.

This repository does not automatically publish to HighLevel. Membership, forms, checkout, and externally hosted tools still depend on their existing services. Do not treat importing their HTML as migrating their backend functionality.

## Scope

Only explicitly supplied website source belongs here. Do not add customer exports, orders, credentials, unrelated archives, or private business documents. No license is granted by this repository; existing source attribution is preserved.
